# Sistema-Oftalmico-DS

##Descripcion
Sistema de manejo de consultas médicas implementado en Java para una oficina oftálmica en Mayagüez, desarrollado para el proyecto de Estructura de Datos. El sistema administra médicos, enfermeros, secretarias y pacientes. Permite gestionar pacientes (evitando duplicados y buscando empleados/pacientes por ID), manejar filas de espera normales (FIFO) y pacientes de urgencia por prioridad, concertar y cancelar citas, asignar pacientes a médicos disponibles, registrar visitas y consultar el historial clínico en orden de visitas recientes y citas completadas recientemente.

## Instalación

## Uso
Ejecuta Main.java desde VS Code o desde la terminal.

Sigue las opciones del menú interactivo en consola para:

Registrar pacientes y empleados, o buscar por ID.

Concertar o cancelar citas, ver las citas de hoy y registrar visitas médicas.

Añadir pacientes a la fila de espera, atender urgencias por prioridad y asignar pacientes a médicos disponibles.

Buscar médicos por especialidad y revisar el historial clínico o las citas completadas recientemente.

## Configuracion
No se requieren variables de entorno ni archivos de configuración adicionales para ejecutar este proyecto en consola.
